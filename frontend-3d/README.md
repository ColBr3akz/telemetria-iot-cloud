# Frontend 3D — Habitación del Paciente

Visualización 3D del domicilio del paciente conectada a la API de FastAPI.

## Requisitos
- Backend corriendo en `http://127.0.0.1:8000`
- Python 3.x (para el servidor local)

## Ejecutar

```bash
# Desde la raíz del proyecto
cd frontend-3d
python -m http.server 5500
